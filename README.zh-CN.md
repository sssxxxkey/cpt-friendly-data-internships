## 收录标准与防诈骗

- **岗位证据**：必须链接到公司官网或其官方 ATS 上的具体职位页。公司官网招聘门户可以作为搜索入口，但不能代替具体职位链接。
- **社媒只作线索**：小红书、微信群、公众号文章、招聘聚合站可以提示我们去查，但不能单独作为收录依据。只有在公司官方招聘页找到对应职位后才会入表，并以官方页为准。
- **不猜关键信息**：发布时间、截止日、学历/毕业届别、地点、远程/混合办公及薪酬都只在官方页面明确写出时记录；未写明就标“未注明”。
- **防诈骗**：不收录要求求职者交报名费、培训费、押金或购买内推的职位；申请只跳转至公司官方页面。即使职位链接是官方的，也请核对域名，谨慎对待索要银行卡、验证码或非必要证件信息的联系。

## 官方招聘入口（发现渠道，不代表目前有对应空缺）

- [字节跳动校园招聘](https://jobs.bytedance.com/campus/)
- [腾讯招聘](https://careers.tencent.com/)
- [阿里巴巴集团招聘](https://talent.alibaba.com/)
- [美团招聘](https://career.meituan.com/)

这些入口用于发现职位。每个岗位仍需点进具体官方职位页确认职位开放状态和申请条件。不同公司的招聘系统结构不一样，所以中国版不会假装所有来源都能被同一个自动爬虫稳定覆盖；暂时无法可靠自动读取的官网职位，会在核实官方页面后再手动登记。

## 更新与反馈

职位按照官方公布的发布日期倒序排列；没有发布日期时，才按首次核验时间排序。岗位是否仍开放以官方页面为准。欢迎通过 GitHub Issue 提供线索，但请附上**具体的公司官方职位页**；不要提交简历、申请记录、身份证件或其他个人信息。
