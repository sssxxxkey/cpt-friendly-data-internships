### 快速看匹配点

- **J78722 数据分析师**：偏核心指标监控、异动归因、看板维护和专题分析；要求里明确提到 SQL / Excel，Python 或 R 为加分能力。页面写“半年以上优先”，需要确认实习时长和到岗安排。
- **J81163 AIGC 数据分析**：偏 AI 内容链路、模型效果与业务指标分析；页面要求每周 5 天、至少 3 个月，并接受本科/硕士在读。
- 这两条都是北京日常实习，不是远程岗位；如果你无法在北京线下实习，就不要把它们当作可投岗位。

## 岗位分类与筛选

### 主列表会收

- Data Analyst / 数据分析师 / 数据分析实习生
- Data Scientist / 数据科学实习生（要求适合本科生的也会收）
- BI / 商业智能 / 经营分析 / 商业分析
- 产品分析、用户增长分析、实验分析（职责主体确实是数据分析）

### 不放进主列表

- 纯算法研究、要求博士或重度模型研发的岗位（可另设“研究/算法”分类，不和 DA 混在一起）
- 数据标注、纯运营或只在描述里顺带提到“数据分析”的岗位
- 纯数据工程、后端开发、制造/工厂数据岗位
- 只有小红书/微信群/付费内推页面、没有公司官方职位页的招聘信息

## 来源与核验

### 官方招聘入口（发现渠道，不代表当前有合适空缺）

- [百度校园招聘](https://talent.baidu.com/)
- [字节跳动校园招聘](https://jobs.bytedance.com/campus/)
- [腾讯招聘](https://careers.tencent.com/)
- [阿里巴巴集团招聘](https://talent.alibaba.com/)
- [美团招聘](https://career.meituan.com/)

每条职位都必须有**具体官方职位链接**。官网入口只是搜索渠道，不等于有职位开放。国内各公司使用不同招聘系统，目前此页面采用“自动化发现 + 官方页核验”的方式；无法稳定读取的招聘系统不会假装已自动覆盖。

### 怎么判断靠谱不靠谱

1. 申请链接的域名应属于公司官网或其官方招聘系统。
2. 职位标题、地点、实习类别、要求能在官方职位页对应上。
3. 截止日期只在官方明确写出时填写；没有写就标“未注明”。
4. 不付申请费、押金、培训费或“保 offer”费用，不向陌生人发送验证码或银行卡信息。
5. 社媒线索如果找不到对应官方职位页，标记为“未核实”，不放进岗位表。
